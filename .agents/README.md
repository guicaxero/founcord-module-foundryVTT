# Especialistas do módulo

Os perfis desta pasta formam o pipeline obrigatório para interfaces do módulo:

```text
UI/UX especifica → Front-end implementa e valida → UI/UX revisa → correções
```

Os documentos não executam agentes isoladamente. O `AGENTS.md` da raiz define
quando delegá-los e quais etapas bloqueiam a conclusão.
